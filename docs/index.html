Plugins, straight from the community.

Visual and logic nodes other people built for Conky Studio's editor — drop one into a project and it shows up on your palette next to the built‑ins.

Every entry here is plain JSON: metadata plus a Lua snippet substituted into your theme. Nothing is compiled or hidden — open any plugin's detail page and read the Lua before you trust it, the same way you would any theme script you didn't write yourself.
